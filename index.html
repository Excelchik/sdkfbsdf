Практическое задание 2. Черепаха рисует (12 мин)

Ученики выполняют три шага ():

  1. Запустить готовую программу и рассмотреть результат.
  2. Изменить длину стороны и цвет так, чтобы получился большой красный квадрат.
  3. Дописать треугольную крышу, чтобы получился «Домик».
from turtle import *
color("red")
forward(100); right(90)
forward(100); right(90)
forward(100); right(90)
forward(100); right(90)
# крыша: допишите сами
left(60); forward(100); right(120); forward(100)

Для подготовленных учеников: в коде учителя есть ошибка (right(60) вместо left(60)). Нужно найти её, объяснить и исправить.

def grade(score):
    if score < 0 or score > 100:
        return "ошибка"
    elif score >= 85:
        return 5
    elif score >= 65:
        return 4
    elif score >= 40:
        return 3
    else:
        return 2

Задание B. «Статистика класса» — 8 класс

Цели
, , ,
Условие
В файле scores.txt каждая строка имеет вид «Имя Балл», последняя строка — END. Нужно вывести средний балл, лучшего ученика и количество работ. Строки с баллом вне 0–100 пропускаются (continue), чтение останавливается на END (break).
Трассировка
Для файла из трёх строк заполнить таблицу значений total, count и best после каждого шага цикла.
total = count = 0
best, leader = -1, ""
with open("scores.txt", encoding="utf-8") as f:
    for line in f:
        line = line.strip()
        if line == "END":
            break
        name, score = line.split()
        score = int(score)
        if score < 0 or score > 100:
            continue
        total += score
        count += 1
        if score > best:
            best, leader = score, name
print("Работ:", count)
print("Средний балл:", round(total / count, 1))
print("Лучший:", leader, best)
